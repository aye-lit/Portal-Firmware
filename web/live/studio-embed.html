Quick install, no Arduino needed

Select the correct board from the drop down list to the right. Plug the board into your computer, click the Install on my board button. Works in Chrome or Edge on a computer. Takes about a minute.

Manual Install

  1. Install the libraries

    In the Arduino IDE, open Library Manager, search and install it. Choose “Install all” so Adafruit GFX comes along.

    This screen needs an ESP32. If you haven't set one up yet: open Boards Manager, search esp32, install “esp32 by Espressif Systems”, then pick your board under Tools → Board.
